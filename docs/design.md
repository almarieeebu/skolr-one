# Design note (one-page workspace)

1. **Layout:** one full-viewport page (`100dvh`, the document never scrolls on desktop). Three panes: a 76px **rail** of module tabs (dark `--ink`), a ~320px **list** (title, waiting count, search, filter chips, dense 56px rows), and the **detail** (header with name, ID, status pill and a one-line 6-step tracker; horizontal sub-tabs; content that scrolls inside; an **action dock** footer with only the buttons the role can press now).
2. **Modules by role:** Registrar: Enrollment, Applicants, Cashier, Grades, Setup. Cashier: Cashier, Enrollment. Teacher: My classes, Students. Dean: Enrollment, Grades. Student/Parent/Applicant: the same shell with portal tabs and no list column when there is one record.
3. **Secondary work** (take payment, discount, void, reply, pick load, new application, change grade) opens a 480px **side panel** (slides 180ms, Esc closes, focus trapped). Short confirmations (needs fix, reject, withdraw, return) use a centered **modal**. Setup forms render in the detail pane.
4. **Color tokens** (`app/globals.css`, dark theme via `prefers-color-scheme`): `--ink #16233F` (rail, primary text, primary buttons), `--paper #F7F9FB` (app bg), `--sheet #FFFFFF` (panes), `--line #DCE3EA` (1px dividers), `--go #1F7A5C` (done/paid), `--warn #B5541C` (needs fix/overdue), `--stop #B42335` (rejected/void), `--muted #5C6B7E`.
5. **Highlight** `--highlight #FFD23F` is used ONLY for "waiting on you": the 4px left stripe on list rows and the count badge on a rail tab. Nothing else is yellow.
6. **Status pills:** 999px radius, ~11% tint of the status color with the status color as text, sentence case. In-progress steps use an ink tint; enrolled/paid use go; needs fix/overdue use warn; rejected/void use stop.
7. **Type:** Plus Jakarta Sans (next/font) 400/500/600/700; scale 12/13/14/16/20/24; body 14px on staff screens, 16px on phones and the public form; `tabular-nums` on money, grades, units, IDs. No all caps, no monospace, no letter-spaced labels, no arrows in buttons, no middle-dot meta strings.
8. **Shape:** radius 6px on inputs/buttons, 10px on panels/modals, 999px on pills. No drop shadows except side panels, modals and menus. Group content with `--line` rules and whitespace, not stacks of cards.
9. **Motion and access:** motion only on user action (panel slide, tab underline), off under `prefers-reduced-motion`. Focus ring: 2px `--ink` outline with offset (white on the rail). Tabs use tablist/tab/tabpanel; dialogs use `role="dialog"` + `aria-modal`. Keyboard: `/` search, Up/Down list, Enter open, `[` `]` sub-tabs, Esc close.
10. **Phones (<768px):** the rail becomes a bottom tab bar; list and detail are two stacked views with a Back button; side panels become full-height sheets; no horizontal page scroll at 390px. `/apply` keeps 4 steps on one page (left step list on desktop, top stepper on phones); `/login` is one centered card.
